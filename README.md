# Secure Financial Transactions & Banking Platform

A full-stack online banking web application built with **Java, Spring Boot, MySQL, and React (Vite)**. 

## 🚀 Live Demo
- **Frontend App:** [View Live Application](https://online-banking-app-nine.vercel.app)

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, RESTful APIs, Multi-threading
- **Database:** MySQL, B-Tree Indexing
- **Frontend:** React, Vite
- **Testing & DevOps:** JUnit, Mockito, Docker, Maven

## ⚙️ Local Setup
1. Clone repository: `git clone https://github.com/KHarshithaaa/online-banking-app.git`
2. Run backend: `mvn spring-boot:run`
3. Run tests: `mvn clean test`
